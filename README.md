# 少儿编程体验课铺课 H5（多 SKU 落地页）

面向 6–12 岁儿童编程体验课的转化用横滑 H5 落地页，一页一屏、左滑翻页、画廊自动轮播 + 灯箱放大。
同一份 HTML 通过 URL 参数切换「铺课版 / 报价版」。

## 目录结构

| 目录 | 班型（对外名称） | 说明 |
|---|---|---|
| `python/` | 科特班英才计划（Python） | 站点首页与其内容相同 |
| `rocket/` | 育才班英才计划（图形化） | |
| `moon/` | 探月科特班英才计划（图形化） | |
| `talent/` | 英才班（图形化 · 入门） | |
| `yucai/` | 育才班（幼儿线 · 图形化） | |

每个目录均为独立站点：`index.html` + `assets/`（webp 物料图），无任何后端依赖。

## 页面结构

- **铺课版**（7 页）：封面 → 01 项目介绍 → 02 成长路径 → 03 学习收获 → 04 课程体系 → 05 师资力量 → 06 赛考/能力规划 → 07 品牌实力
- **报价版**（8 页）：在链接后加 `?price=1`，追加「08 · 直播间专享」报价页；不加参数时第 08 页及导航刻度会被脚本自动移除

## 技术要点

- 单文件实现：每个 SKU 一个 `index.html`（内联 CSS/JS），部署为纯静态托管
- 横滑翻页：`.deck/.slide` + scroll-snap，右侧贴边「左滑翻页」提示（末页自动隐藏）
- 循环画廊：`.gallery[data-gallery]` 等高不等宽，卡片宽度 = 行高 × 图片比例（`--ar`），JS 自动克隆实现无缝循环
- 灯箱：`data-pics` 注册的容器点击放大，支持双指/按钮缩放
- URL 规范化：head 内置脚本自动补尾斜杠，避免静态托管在 `/sku`（无斜杠）下相对路径图片 404
- 移动端优先：390px 设计稿，`@media(min-width:900px)` 提供桌面档

## 本地预览

直接双击各目录的 `index.html` 即可；或起个静态服务：

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080/python/
```

## 部署

任意静态托管均可（本项目使用腾讯云 CloudBase 静态托管），把各目录整体上传：

```
/python/  →  kete-h5-preview/
/rocket/  →  kete-rocket/
/moon/    →  kete-moon/
/talent/  →  kete-baby/
/yucai/   →  kete-yucai/
```

注意事项：

1. **必须带尾斜杠访问**（`/python/` 而不是 `/python`），页面内已有脚本兜底
2. 改动后注意客户端缓存（HTML 缓存约 5 分钟），必要时带 `?v=时间戳` 强制刷新
3. 画廊加减图时，每个 `<button class="gl-i">` 必须同步 `style="--ar:宽÷高"`，否则卡片宽度错位
